El objeto Math

El objeto Math es un objeto integrado en JavaScript que permite realizar tareas matemáticas. A continuación se detalla el uso de cada función con su respectivo ejemplo:

Math.abs(x)

Para qué sirve: Devuelve el valor absoluto de un número (es decir, convierte los números negativos en positivos y los positivos los deja igual).

Ejemplo:

JavaScript console.log(Math.abs(-7.25)); // Devuelve: 7.25

Math.round(x)

Para qué sirve: Redondea un número al entero más cercano. Si la parte decimal es .5 o mayor, redondea hacia arriba; de lo contrario, hacia abajo.

Ejemplo:

JavaScript console.log(Math.round(4.5)); // Devuelve: 5 console.log(Math.round(4.4)); // Devuelve: 4

Math.ceil(x)

Para qué sirve: Redondea un número hacia arriba al entero más cercano (techo), sin importar si el decimal es pequeño.

Ejemplo:

JavaScript console.log(Math.ceil(4.1)); // Devuelve: 5

Math.floor(x)

Para qué sirve: Redondea un número hacia abajo al entero más cercano (piso), descartando la parte decimal.

Ejemplo:

JavaScript console.log(Math.floor(4.9)); // Devuelve: 4 Math.exp(x)

Para qué sirve: Devuelve el valor de $e^x$, donde $e$ es la constante de Euler (aproximadamente 2.71828) elevada a la potencia del número x.

Ejemplo:

JavaScript console.log(Math.exp(1)); // Devuelve: 2.718281828459045

Math.log(x)

Para qué sirve: Devuelve el logaritmo natural (en base e) de un número.

Ejemplo:

JavaScript console.log(Math.log(10)); // Devuelve: 2.302585092994046

Math.random()

Para qué sirve: Devuelve un número pseudoaleatorio de punto flotante que va desde 0 (inclusive) hasta 1 (exclusivo).

Ejemplo:

JavaScript console.log(Math.random()); // Devuelve algo como: 0.613947
